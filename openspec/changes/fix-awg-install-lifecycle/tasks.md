# Tasks

## 1. Допуск и результат запроса установки

- [ ] 1.1 Воспроизвести ошибку через POST установки `awg3` с временным файлом состояния, подменой SSH и управляемым событием завершения установщика. Сократить `RESPONSE_WAIT_SECONDS` в тесте и подтвердить, что текущий маршрут отвечает 503 с кодом `peer_lifecycle_still_running` до снятия события.
- [ ] 1.2 Включить ожидание завершения на маршруте установки. В том же тесте проверить, что запрос остаётся активным за пределом сокращённого срока, затем возвращает журнал и ключ сохранённого экземпляра при единственном вызове установщика. Отдельным исходом проверить позднюю ошибку сборки и отсутствие новой записи протокола.
- [ ] 1.3 Проверить допуск через тот же маршрут при занятой блокировке и активном маркере неопределённости. Убедиться, что первый случай возвращает 503, `peer_lifecycle_busy` и `Retry-After`, второй — `peer_lifecycle_uncertain`, а число вызовов установщика в обоих случаях равно нулю.
- [ ] 1.4 Проверить отмену ожидания после допуска и потерю ответа SSH во время установки. Конкурирующий запрос должен оставаться заблокированным до выхода первого исполнителя, а после неопределённого результата SSH последующий запрос должен требовать восстановления. Прогнать существующие тесты `test_peer_recovery_review.py` и `test_awg_plugin_lifecycle.py`.

## 2. Окно установки

- [ ] 2.1 Заменить смену этапов по таймеру на индикатор ожидания. В проверке поведения окна задержать ответ и убедиться, что до его получения не появляются этап сборки, процент завершения или сообщение об успехе.
- [ ] 2.2 Различить отказ до запуска, требование восстановления, старый код продолжающейся операции и ошибку установщика. Проверить эти ответы в окне, включая отображение многострочного текста ошибки. Добавить и сверить ключи сообщений во всех поставляемых переводах.
- [ ] 2.3 Обработать разрыв соединения и ответы прокси 502/504 с неизвестным итогом. Проверить первую установку, переустановку и добавление экземпляра при уже видимом базовом контейнере. Окно должно предложить проверить состояние и отправить только один POST установки.
- [ ] 2.4 Проверить обычный успешный ответ общего маршрута для `awg3` и ещё одного протокола. Журнал установщика, предупреждения и обновление карточки сервера должны по-прежнему отображаться после завершения.
