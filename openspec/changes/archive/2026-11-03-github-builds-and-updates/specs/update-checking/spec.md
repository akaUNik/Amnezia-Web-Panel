# Spec Delta

## Purpose

Определяет проверку доступной стабильной версии панели по релизам основного репозитория и понятное отображение результата администратору без автоматической установки.

## ADDED Requirements

### Requirement: Main repository update source
Проверка обновлений SHALL использовать только стабильные опубликованные релизы `akaUNik/Amnezia-Web-Panel`. Draft, prerelease и обычные коммиты main SHALL не предлагаться как стабильные обновления. Проверка публичных релизов SHALL работать без пользовательского токена GitHub.

#### Scenario: Stable release lookup
- **WHEN** администратор запускает проверку в настройках
- **THEN** панель получает стабильный релиз основного репозитория без запроса к релизам PRVTPRO или GitVerse

#### Scenario: Prerelease exists
- **WHEN** после стабильного релиза опубликован предварительный релиз
- **THEN** проверка продолжает использовать стабильный канал

### Requirement: Semantic version comparison
Панель SHALL сообщать о новой версии только если стабильная версия релиза больше текущей по SemVer. Префикс `v` и build metadata SHALL не менять порядок; числовые компоненты SHALL сравниваться численно, а prerelease SHALL предшествовать соответствующей стабильной версии.

#### Scenario: Higher minor version
- **WHEN** текущая версия `v1.9.0`, а стабильный релиз `v1.10.0`
- **THEN** панель сообщает о новой версии

#### Scenario: Equal or older release
- **WHEN** текущая версия `v1.9.0`, а релиз `1.9.0` или `v1.8.4`
- **THEN** панель сообщает, что более новая стабильная версия не найдена, и не предлагает откат как обновление

#### Scenario: Current prerelease
- **WHEN** текущая версия `v1.9.0-rc.1`, а стабильный релиз `v1.9.0`
- **THEN** панель сообщает о новой стабильной версии

#### Scenario: Unknown version format
- **WHEN** текущая версия или тег релиза не распознаётся как SemVer
- **THEN** панель сообщает о невозможности автоматического сравнения и предоставляет ручную ссылку на релизы

### Requirement: Explicit check outcomes
Панель SHALL различать новую версию, отсутствие более новой версии, отсутствие опубликованного стабильного релиза и ошибку проверки. Сетевой сбой, timeout, ограничение API и некорректный ответ SHALL не отображаться как актуальность установленной версии.

#### Scenario: No stable release
- **WHEN** источник не содержит опубликованного стабильного релиза
- **THEN** панель сообщает об отсутствии такого релиза и оставляет доступной ручную ссылку

#### Scenario: GitHub unavailable
- **WHEN** API возвращает 403, 429, 5xx, некорректный JSON или не отвечает в пределах timeout
- **THEN** панель показывает ошибку проверки и позволяет повторить её

#### Scenario: Request finished
- **WHEN** проверка завершилась любым результатом
- **THEN** индикатор загрузки скрыт и кнопка проверки снова доступна

### Requirement: Trusted download destination
Ссылки обновлений SHALL вести в раздел релизов `https://github.com/akaUNik/Amnezia-Web-Panel/releases`. Текст версии SHALL отображаться как текст без исполнения HTML из ответа API. Ручная ссылка SHALL быть доступна независимо от результата автоматической проверки.

#### Scenario: Unexpected release URL or markup
- **WHEN** ответ API содержит посторонний `html_url` или HTML в `tag_name`
- **THEN** панель не переходит на посторонний адрес и не исполняет разметку

### Requirement: Localized update feedback
Проверка SHALL показывать результат на выбранном языке панели для всех пяти существующих локалей: en, ru, fr, zh и fa.

#### Scenario: Russian language
- **WHEN** администратор с выбранным русским языком получает ошибку API или отсутствие релиза
- **THEN** состояние проверки и доступные действия подписаны по-русски
